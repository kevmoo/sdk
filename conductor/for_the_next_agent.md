# Handover Notes for the Next Agent

You are taking over Project Socket2. The project has moved from a raw socket prototype to a fully integrated, verified `package:shelf` implementation.

## Key Accomplishments in this Session

1.  **Full End-to-End Integration**:
    *   Implemented `Socket2ShelfServer` in `package:bottom_shelf`.
    *   Unified HTTP logic (validation/preparation) into a shared `HttpProtocol` class used by both legacy and `Socket2` implementations.
    *   Successfully isolated experimental `Socket2` bits into `lib/shelf_socket2.dart`, restoring System Dart compatibility for the main package.

2.  **SDK Robustness & Concurrency Fixes**:
    *   **The "Would Block" Bug**: Fixed a critical hang where `Socket2` failed to re-register interest when a native call returned `EWOULDBLOCK`. Resolved by using `setListening(..., issueEvents: false)`.
    *   Added `tests/standalone/io/socket2_concurrency_test.dart` (100 concurrent connections).
    *   Added `tests/standalone/io/socket_large_stream_test.dart` (100MB legacy stream regression test).

3.  **Benchmark Matrix established**:
    *   Created a multi-dimensional benchmark (`pkgs/bottom_shelf/benchmark/matrix.dart`) comparing:
        *   **Runtimes**: SYSTEM Dart vs. CUSTOM SDK.
        *   **Modes**: JIT vs. AOT.
        *   **Servers**: `shelf_io`, `bottom_shelf` (legacy), `socket2` (experimental), `dart:io`.
    *   Eliminated File I/O noise from benchmarks by using in-memory generated bytes.

## Critical Performance Observations
*   **The "Real World" Gap**: While raw `Socket2` benchmarks hit 1.5GB/s, the `Socket2ShelfServer` currently trails legacy `bottom_shelf` in RPS for small payloads (~31k vs ~58k).
*   **The AOT Mystery**: `Socket2` performance on large streams drops significantly in AOT (e.g., ~1700 RPS in JIT vs ~200 RPS in AOT).
*   **The "Slam Dunk" is missing**: We need to understand why the throughput wins at the socket layer are being eaten by overhead at the HTTP/Shelf layer.

## Next Steps & Research Priorities

1.  **Investigation: Performance Degredation**:
    *   Profile the AOT vs JIT execution for `/stream`.

2.  **Benchmark Refinement**:
